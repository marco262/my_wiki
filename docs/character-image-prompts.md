# Character Image Prompt Guidance

Use this doc when writing prompts for generated images that include recurring named characters. The goal is to make prompts consistent enough that images feel like they belong to the same campaign, while still giving each scene distinct composition and energy.

## When to Use This

Use this guidance when:

* writing prompt sheets for GM notes or adventure prep
* generating a new scene with recurring PCs or NPCs
* revising prompts that feel too generic or that produce muddy staging
* trying to keep a cast visually consistent across multiple images

Do not use this level of detail for:

* pure object shots
* simple maps
* monster-only or location-only images with no important recurring characters

## Core Principle

For character images, specify three things clearly:

1. **Who the character is**
2. **What the character is doing**
3. **How the camera sees them**

Most weak prompts fail because they only do the first one.

## Character Naming

When the user has an established preference, follow it exactly. For Class 1A, use the short names the user preferred in prompts:

* `Alyse`
* `Gren`
* `Meli`
* `Timtom`
* `Miss Ellee`

Use full names only when the user asks for them or when the character is not part of the usual short-name set.

## Reference Image Workflow

If the user already has a strong reference image for the class or a character, treat that as the primary consistency anchor.

Recommended preamble:

```text
Use the attached class or character reference image to keep the students consistent with prior images. Match their established appearance closely while placing them naturally into the new scene.
```

When reference images are available:

* rely less on restating facial identity from scratch
* still specify pose, demeanor, and camera angle
* still specify scene-specific actions and hand placement

Reference images help with likeness. They do not replace composition instructions.

## What to Specify for Each Character

For each named character in a scene, include as many of these as matter:

* **Role in the shot**
  Example: closest to the corner, farther back, centered, off to one side
* **Facing relative to camera**
  Example: `3/4 front view`, `3/4 back view`, `partial side profile`, `near side profile`, `body angled away while face turns back`
* **Feet and balance**
  Example: one foot forward, weight thrown backward, feet planted wide, on the balls of their feet, heel lifted, knees bent
* **Hands and arms**
  Example: finger raised in a silence gesture, hand near belt, hand braced on desk, both hands on table edge, one hand open at side, hands clasped in front
* **Torso and shoulders**
  Example: leaning forward, shoulders squared, shoulders dropping with relief, torso twisted toward a statue, body angled toward the crowd
* **Eye line**
  Example: eyes cut back toward the Stone, staring up at the predator, looking past the headmaster, scanning the doorway
* **Expression**
  Example: guarded social awareness, anxious fascination, measured skepticism, calm protective suspicion
* **Overall demeanor**
  Example: grounded calm, teacherly tension, disciplined vigilance, exhausted concentration

Do not stop at “curious” or “tense.” Say what the tension looks like physically.

## Scene Composition Guidance

For scenes with multiple characters, also specify:

* camera height
  Example: low near the floor, knee height, eye level, slight overhead
* viewing angle
  Example: from mid-hall, from inside the office looking diagonally across it, slightly past one foreground figure toward the others
* arrangement
  Example: loose triangle, staggered down the hallway, one foreground / one midground / one background

If the image is meant to be used at the table, composition clarity matters more than maximal detail.

## Variety Across a Set

When writing a prompt sheet for a full adventure, do not keep reusing the same two characters in every image. Spread character presence across the set.

Good practice:

* rotate which students appear together
* use the whole class only in broad establishing scenes
* use 1-3 characters in most action or investigation shots
* reserve solo portrait treatment for major NPCs

This keeps the image set from feeling repetitive and gives more of the cast visual presence.

## Archetype Notes for NPC Portraits

For important NPC portraits, add a short plain-English archetype note before the prompt. This helps lock in the emotional and social read before visual details start.

Good examples:

* `exhausted truth-teller`
* `polished institutional antagonist`
* `disciplined professional authority figure`

Then translate that archetype into:

* age range
* face and eye description
* hair and grooming
* outfit silhouette and palette
* accessories
* posture and hand placement
* expression and demeanor

The archetype should explain how the character feels in plain English before the prompt explains how they look.

## Prompt Writing Pattern

For a strong scene prompt with recurring characters, the usual pattern is:

1. Establish the scene and environment
2. State camera position or composition
3. Place each named character in the scene
4. Describe each character's pose, facing, hands, feet, expression, and demeanor
5. End with style, tone, and exclusion notes

## Good Character Prompt Moves

Use phrases like:

* `shown mostly in 3/4 back view`
* `body angled toward X while eyes cut toward Y`
* `one hand braced on the desk`
* `one foot sliding back for balance`
* `hands clasped in front of him`
* `one forearm lifted against the force`
* `one hand half-raised as if warning someone`
* `leaning forward from the side`

These phrases tend to produce better staging than broad emotional language alone.

## Things to Avoid

Avoid prompts that:

* list names with no poses
* describe emotion but not body language
* put too many characters into a medium-complexity shot
* repeat the same arrangement across multiple images
* overdescribe costume while underdescribing action
* rely on “dynamic” or “cinematic” as a substitute for blocking

Avoid generic wording like:

* `standing there`
* `looking at the scene`
* `curious expression`
* `tense atmosphere`

Replace those with specific physical instructions.

## Practical Standard for Future Prompt Sheets

When asked to generate image prompts that include characters, default to this process:

* identify which images actually benefit from named characters
* use short preferred names when the user has established them
* add a reference-image note if a strong class or character image exists
* specify camera angle and character facing
* specify hands, feet, and posture for each named character
* specify expression and demeanor for each named character
* vary the cast across the image set instead of repeating the same pairings
* give major NPC portraits an archetype note plus detailed visual brief

If the user asks for image prompts in the future, consult this doc by default.
